# 🎮 게임 파티 매칭 플랫폼 '5ASIS' (Full-Stack)

사용자 간 게임 파티 모집과 정보 교류를 돕는 웹 서비스입니다.
팀 프로젝트에서 **회원가입/로그인 화면 구현 및 세션 기반 사용자 인증, 서버 측 CRUD 로직**을 집중적으로 담당했습니다.

## 👩🏻‍💻 나의 기여도 및 담당 역할

**1. 프론트엔드 UI 및 사용자 인증 로직 구현**
- 회원가입 및 로그인 페이지 UI(총 2개 화면)를 구현했습니다.
- 세션 기반의 사용자 인증 로직을 구축하여 로그인부터 로그아웃까지의 전 구간 흐름을 제어했습니다.

**2. 백엔드 API 및 데이터베이스 연동**
- Spring MVC와 MyBatis를 활용하여 서버 측 CRUD 로직을 개발했습니다.
- Oracle 데이터베이스를 연동하고 쿼리(SQL)를 직접 작성하여, 프론트엔드와 서버 간의 데이터 구조를 협의하고 통신을 구현했습니다.

**3. 트러블슈팅 (Troubleshooting)**
- **세션 인증 문제 해결:** 세션 처리가 정상적으로 이루어지지 않던 문제를 브라우저 네트워크 탭과 서버 오류 로그를 대조하여 추적하고 원인을 파악해 해결했습니다.

**4. 기획 및 커뮤니케이션**
- 프로젝트 기획 발표를 전담하여 기획 의도와 기술적 목표를 팀 외부로 전달하는 역할을 수행했습니다.

## 🛠 사용 기술 (Tech Stack)
- **Frontend:** React / JavaScript
- **Backend:** Java / Spring MVC / MyBatis / Apache Tomcat
- **Database:** Oracle DB
